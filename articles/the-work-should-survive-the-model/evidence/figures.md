published sentence.

### Why the result is not described as an agent handoff

The plain-language distinction is grounded in
`src/modules/learning/learning_approach_memory.c`,
`src/modules/learning/include/aimee/learning/approach_memory.h`,
`src/approach_store.c`, `src/tests/test_approach_memory.c`,
`docs/features/economizer.md` and
`docs/features/tool-output-condensation.md` in PR #2873's source tree.

Those sources support the narrower product claims made in Article Zero:

- the originating run can end before a later model receives the lesson;
- source identity remains provenance inside the authorised shared KB rather
  than restricting recall to one user, session or model;
- repeating the same no-progress failure reinforces one stable row;
- a sufficiently similar goal recalls the advisory while an unrelated goal
  receives nothing;
- the rendered failed approach is advisory evidence rather than an imperative
  instruction; and
- the economizer can fold or condense older tool output while retaining a
  scoped recovery path to the full bytes.

The comparison to a workflow-local summary or a permanent instruction file is
architectural analysis. It does not claim that no other harness can persist or
retrieve a summary. The complete-product market claim remains separately
scoped below.

## Academic and commercial boundary update, 2026-08-27

The broad claim that no prior work demonstrated cross-model experiential memory
improving task outcomes does not survive source review and is not published.

[Recuris](https://arxiv.org/abs/2608.24876), submitted 25 August 2026, evolves a
skill-memory package from one deployment model and evaluates that unchanged
package across other frozen models. It reports programmatically graded gains on
four long-horizon benchmarks. It is implemented benchmark research, not merely
a theoretical proposal.

The relevant product distinction is narrower. Recuris does not present or
evaluate an organisation-scoped production service with multi-user
authorisation, provenance and correction history, independent execution and
credential isolation, or tamper-evident audit. Aimee has current first-party
production use, while the named professional fields describe intended scope.
The new controlled cross-model effect uses a real large repository and sealed
repair grader.

Adjacent commercial documentation was rechecked for shared organisational
memory:

| product | primary documentation | documented overlap | limit of the public evidence reviewed |
|---|---|---|---|
| GitHub Copilot Memory | [Copilot Memory](https://docs.github.com/en/copilot/concepts/agents/copilot-memory) | repository facts can be reused by users with memory access and validated against code | no public controlled result found in which one model's failure raises another model's graded task capability |
| Devin | [Knowledge](https://docs.devin.ai/product-guides/knowledge) and [advanced capabilities](https://docs.devin.ai/work-with-devin/advanced-capabilities) | organisation knowledge, session-outcome analysis and knowledge access from MCP agents | no public production claim found that closes Aimee's full scoped learning, isolated execution and independent audit loop |
| Cursor | [Memories](https://docs.cursor.com/en/context/memories) and [rules](https://docs.cursor.com/context/rules) | project memories and versioned team rules | public docs describe memory/rules, not the complete outcome-to-governed-learning loop |

These products remain adjacent categories, not asserted direct competitors. The
review is not a census of private systems. Before publication, any named
product receiving a material comparison should be offered the exact comparison
and a reasonable right of reply.
