# Source questions: projects cited in the Perseus article

Status: draft. Not sent.

These are source-verification questions. The cited projects are evidence of
earlier technical work; the article does not criticise their maintainers. No
maintainer is being asked for a patent-validity opinion.

Rakuen develops Aimee and has a commercial interest in the comparison. Aimee's
dates and capabilities must be supported by Rakuen's records and disclosed as
first-party evidence. We cannot turn ourselves into an independent source by
sending ourselves an interview request.

## Questions for every project

1. What is the earliest public release, commit, paper or design document that
   supports the capability attributed to your project in our article?

2. Does our technical description accurately state what the project did at
   that date? Please identify anything that appeared later or remained a
   proposal.

3. Was the cited work developed independently of Perseus Computing LLC and
   Thomas Connally?

4. Did your project or its maintainers exchange code, designs, licensing terms
   or technical material with Perseus before May 2026?

5. Has Perseus contacted you about its patent filings, defensive publications
   or description of the prior art?

6. Please identify any correction and any earlier public record that documents
   the capability more clearly.

## Project-specific follow-ups

### Aider

7. By October 2023, did Aider automatically build a tree-sitter repository map,
   rank a dependency graph against a token budget and send the selected map with
   model requests?

### Continue

8. When did Continue first ship typed context providers for files, code, diffs,
   terminal output, repository structure or external services?

9. When did Continue first concatenate project rules or other selected context
   into model requests?

### Cursor

10. When did Cursor first support `@Files`, `@Folders`, `@Code`, documentation,
    Git history or persistent project rules as model context?

11. When did path-based or relevance-based rule selection first ship?

### Anthropic and Claude Code

12. When did Claude Code first load `CLAUDE.md` at session start, run lifecycle
    hooks and give sub-agents fresh scoped context?

### GitHub Copilot

13. When did Copilot first add repository instruction files to requests?

14. When did recursive instruction imports gain depth, cycle and size guards?

### Repomix

15. By October 2024, was Repomix being used to create token-bounded repository
    artifacts for Claude Projects or other model-context workflows?

### Cline

16. The article cites a February 2025 community discussion describing project
    files, a memory bank, MCP-backed memory and cross-tool reuse. Which of those
    capabilities had shipped by then, and which remained proposals or user
    practice?

### Microsoft AutoGen

17. By 2023, did AutoGen provide persistent multi-agent conversation and
    coordination? Which public release best establishes that date?

### Claude Task Master

18. Before May 2026, did Task Master track task state and dependencies and
    select work that was ready for an agent? Which release first did so?

### Beads and claude-flow

19. What task claiming, shared state, dependency tracking, swarm coordination
    or memory capabilities had each project released before May 2026?

20. Do the April 2026 artifacts cited in our article describe shipped behaviour
    at that date?

### LlamaIndex

21. In `v0.10.17`, did LlamaIndex hash node and transformation inputs, cache the
    results and skip work for unchanged document hashes?

22. Which release or document first established that behaviour?

### Prompt Cache, RAGCache and TurboRAG authors

23. Does our article accurately describe Prompt Cache as precomputing reusable
    attention states, RAGCache as caching retrieved knowledge states and
    TurboRAG as precomputing document KV caches offline?

24. What publication and public-access dates should we use for each system?

### CogniRepo

25. Does Perseus's public competitive analysis accurately describe CogniRepo as
    code-first and as overlapping Context Engine and Vault memory?

26. Had CogniRepo or its maintainers communicated with Perseus before that
    competitive analysis was published?

### Foundational systems and standards

27. For GNU m4, Docutils, Org Babel, Make, Bazel and XACML, does our article
    accurately describe the documented parser, directive, dependency, cache or
    policy behaviour it attributes to each system?

28. For Hearsay-II and Maildir, does our article accurately distinguish the
    historical shared-blackboard and crash-safe-publication mechanisms from the
    later agent-task use to which Perseus applies them?
